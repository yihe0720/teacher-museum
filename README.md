# 致您 · 私人博物馆

一份教师节私人礼物。四个展厅分别是风华、才识、温意、可爱，唯一的主角是“您”。完整网页已经接入文档中对应的真实照片、展签、三维实物和空间交互。

## 直接放到 GitHub

解压 `museum-github.zip`，将解压后所有文件上传到仓库根目录。根目录要直接包含 `index.html`、`app.js`、`architecture.js`、`navigation.js`、`content.js`、`style.css`、`assets` 和 `vendor`，不要多套一层文件夹。

在 GitHub 仓库里打开 Settings → Pages，在 Source 中选择 Deploy from a branch，分支选 main，目录选 /(root)，然后 Save。无需 npm，无需构建，无需密钥或后台。页面使用相对路径，支持 GitHub 项目仓库的子目录网址。操作依据：[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

这个包已经包含全部展览照片和依赖，运行时不访问外部图片、字体、播放器或 CDN。常规 GitHub Pages 网页会公开可访问，私有仓库本身不等于网页私密；这份包尚未代您上传 GitHub。

## 本地打开

不要双击 `index.html` 后通过 file:// 打开，因为浏览器会限制 JavaScript 模块。Windows 安装 Python 后，在解压目录的地址栏输入 cmd，回车，在命令窗口输入：

```
python -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。也可以使用已有的本地静态网页服务器。

## 参观操作

- 鼠标或单指拖动环顾，点击圆点移动到观察点。
- 点击展品先走近，再次点击或按左下方「读展签」打开详情。
- 「按路线参观」按策展顺序经过入口题记和展品，点击右箭头才前进，不自动播放。
- 展馆地图可直接换厅，室内以平滑镜头移动，厅间以短暂淡入淡出过渡。
- 风华厅的「一份民间记录」藏在真实可拉开的三维档案抽屉里，点击「拉开抽屉」后才出现。
- 实物详情可以拖动旋转咖啡杯、水瓶、笔和金色足球奖杯；前三件另可展开对应原始照片。
- 温意厅的「安心」在靠近后逐渐显示最后一行；终厅结语之后，约 4.5 秒出现最后一句祝福。
- 所有音乐相关材料均以静态照片展示，没有音乐、视频或播放器。
- 可随时使用「静赏」「视角归正」「减少镜头移动」。方向键环顾，Enter 前进，Esc 关闭弹窗或退出静赏。

## 修改内容的位置

- `content.js`：馆名、序言、四厅入口文字、全部展签、结语、照片文件名。正式展签尽量保留给定原文，仅将“帅气成都”改为“帅气程度”，并合并了用于排版的零散换行。
- `architecture.js`：六个空间的尺寸、建筑、陈设、展品位置、四种物件的三维模型。
- `navigation.js`：家具占地与避让路径。
- `style.css`：手机和桌面的界面布局。
- `assets/素材对应表.md`：原文档图片与文件名的对应关系、纳入/排除说明。

需要改序言时，同时修改 `content.js` 的 prologue 文本即可；序厅实体墙直接读取这一段配置。照片文件名更改后，同步修改内容配置与建筑中对应的照片名称。

## 真实性与素材

照片保持原图，没有替换脸部、虚构课堂内容、补造踢球照片或将音乐材料改成播放器。才识厅书页及书脊不编造讲义与书名；墙面仅提取截图里确实存在的两句话。足球空展位有空框、深绿地面和灯光，没有图像。金色足球奖杯是为该展位制作的三维造型，不是奖杯实物照片。咖啡、水瓶和笔依照原照片的形状与配色制作；原照片保留供查看。

文档中“会议邀请”和“确认成为学生”的聊天截图未纳入展览或网页包，避免偏离这次主题。未把原始 Word 文件一并放进网页。
